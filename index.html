🎮 دسته PS4:

آپشن = توقف
در منو: D-pad یا شوک چپ = ناوبری، ✕ = انتخاب، ○ = بازگشت

WASD / جهت‌دار = حرکت · ماوس = هدف
Space = شعله · P / Esc = توقف

📱 موبایل:
کشیدن انگشت = حرکت و هدف‌گیری
